# Raphael

`// notes that know what they are for`

Raphael is a second brain for agents. It combines PARA for organizing knowledge with CODE for moving that knowledge from capture to useful expression. The goal is actionable notes with context and intent, not a drawer full of links nobody opens again.

The repository is currently a pnpm monorepo foundation. The Expo mobile app, backend, web app, and shared packages have not been scaffolded yet.

## Prerequisites

- Node.js 26.8.1
- pnpm 12.3.4 through Corepack

## Setup

```sh
pnpm install
pnpm dev
```
